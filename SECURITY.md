# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues. Contact the repository owner privately through GitHub.

## Security expectations

- Never commit credentials, API keys, session cookies, or production data.
- Validate and constrain external inputs.
- Respect source API terms, robots policies where applicable, and rate limits.
- Keep dependencies updated and use least-privilege credentials.
- Do not expose internal service ports publicly by default.
